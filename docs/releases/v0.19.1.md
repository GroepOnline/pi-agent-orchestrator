### What changed

- Added the bounded Explore handoff terminal demo tooling now present on `main`, including deterministic handoff parsing checks and recording choreography.
- Added the GroepOnline Pi extension install helper used by the demo.
- Hardened demo recording so it verifies a live MiMo route before capture and does not perform unverified binary downloads or mutate global Pi trust.

### Dependency refresh

- Updated `posthog-node` from 5.50.0 to 5.51.4, including the matching PostHog core/types updates.
- Updated the Pi development host stack to the 0.84.4 line (`pi-agent-core` and `pi-coding-agent`) together with Biome 2.5.12 and current Node.js type definitions.
- Revalidated typecheck, lint, package contract and the orchestration test suite against the combined dependency state.

### Release scope

This patch keeps the v0.19 orchestration/runtime behavior intact and publishes the reviewed `main` state after stale branch convergence. Historical branches whose behavior is already present on `main`, or is superseded by newer policy, are not replayed into the release.
